# 形式美学候选实验特征与图表证据

本目录记录 568 张**候选**图像的探索性特征与图表：姑苏 459、桃花坞 9、杨柳青 100。这 568 张全部属于分类用 892 张图像；不增加图像，也不构成已经人工冻结的最终形式分析集。数据库 `formal_candidates.include_in_analysis` 全为 0。

逐图、逐对 CSV 的 `sample_id` 已统一到公开 `IMG-` 编号，原始来源路径及藏家姓名字段已移除；浮点特征值未改动。`gram_embeddings_public.npz` 只更换编号数组，两个 Gram 特征矩阵逐元素不变。公开 PNG 图中只保留候选指标或质控示例；色彩图明确标为“依据论文汇总数绘制，未独立重算”。

现存代码和参数在 `../code/formal_candidate/`。这些是当前候选运行的版本证据，其默认路径依赖原项目目录，不能直接宣称在此脱敏目录一键重跑。论文中的正式形式分析身份、作品/版次独立性和表7色彩逐图证据仍缺失。详见 `../RESULT_TRACEABILITY.md`。
