# 形式特征候选数据

本目录记录 568 张**候选**图像的探索性特征与图表：姑苏 459、桃花坞 9、杨柳青 100。这 568 张全部属于分类用 892 张图像；不增加图像，也不构成已经人工冻结的最终形式分析集。数据库 `formal_candidates.include_in_analysis` 全为 0。

逐图、逐对 CSV 的 `sample_id` 已统一到公开 `IMG-` 编号，原始来源路径及藏家姓名字段已移除；浮点特征值未改动。`gram_embeddings_public.npz` 只更换编号数组，两个 Gram 特征矩阵逐元素不变。PNG 图展示候选指标或质控示例。

现存代码和参数在 `../code/formal_candidate/`。这些代码的默认路径依赖原项目目录，在此脱敏目录运行前需适配路径。候选组别、作品/版次独立性尚未完成逐图人工确认；本目录也不提供逐图色彩特征。
